# Publication scope

Included: active foundation source and tests, locked Swift dependencies, upstream notices, public source build/test scripts, contribution map and summarized verification evidence.

Excluded: earlier implementation copies, private thinking/friction/session logs, raw binary/UI research, unfinished case-study copy, unreviewed artwork experiments, original Kivi asset/font/sound caches, model weights, personal recordings, local databases, environment files and signing material.

Only the reviewed snapshot is added to the already-public repository history. Local development commits containing the excluded material are not pushed. This repository therefore has a different commit history from the full local development checkout.
